# 電子メールのしくみ（教育用）

送信ボタンを押してから相手に届くまで、電子メールがどこを通っていくのかを、図とアニメーションで1ステップずつ確かめながら学ぶ教育用の Web アプリです。

## 学べること

全5章・23枚のスライドで、教科書の「電子メールのプロトコル」（図3 URL とドメイン名・表1 JP ドメイン名の種類・図4 電子メールのしくみ）に沿って、問題を解きながら進めます。

1. **メールのしくみ**：郵便とのたとえ、メールアドレスの「ユーザ名＠ドメイン名」、URL とドメイン名（スキーム名・ホスト名・組織名・組織種別・トップレベルドメイン）と JP ドメイン名の種類（co.jp・ed.jp・go.jp など）、メールが届くまでの流れ（教科書の図4の ①送信 → ②DNS の返答をもとに転送 → ③メールボックスに保存 → ④POP/IMAP で読む）
2. **送る（SMTP）**：サーバどうしの SMTP の会話（HELO・MAIL FROM・RCPT TO・DATA・QUIT）、DNS の MX レコードで相手のメールサーバを探すしくみ、宛先をまちがえたときのエラーメール
3. **受け取る（POP・IMAP）**：端末にダウンロードする POP と、サーバに置いたまま読む IMAP のちがい（IMAP はサーバの容量を超えると保存・閲覧できなくなる）、教科書の問題1、SMTP・POP・IMAP の仕分け
4. **メールの中身**：ヘッダと本文（Received・From・To・Subject・Message-ID など）、To・CC・BCC のちがい、添付ファイルの Base64 変換
5. **安全に使う**：SSL/TLS による暗号化、フィッシングメールの見分け方、まとめの比較表、10問のまとめテスト（採点・見直し付き）

### 見て確かめる

- **メールが届くまでの図**：たろうの PC・送信サーバ・DNS サーバ・はなこの受信サーバ・スマホの間を、✉️ や ❓ が矢印に沿って動きます。「1つ進める」で1ステップずつ進み、区間ごとに SMTP・DNS・POP/IMAP のどれを使うかと、教科書の図4の番号（①〜④）が表示されます
- **宛先シミュレーター**：正しいアドレス・ユーザ名のまちがい（hanaco）・ドメイン名のまちがい（exmaple）の3つを送り比べ、どこでエラーになりエラーメールが返ってくるかを確かめます
- **POP と IMAP の比較**：パソコンとスマホで受信・既読の操作をして、サーバのメールボックスと端末のメールがどう変わるかを左右に並べて比べます。サーバの容量（5通）がいっぱいになると、新しいメールを保存できないことも確かめられます
- **メールのソース**：メールソフトの画面と、その裏のヘッダ・空行・本文を切りかえて見られます。行をクリックすると説明が出ます
- **To・CC・BCC**：3人の宛先の欄を切りかえて、それぞれの受信者の画面に何が表示されるかを見比べます

### 問題の種類

- **予想問題**：アニメーションの前に「どうなると思う？」と考える問題。答えるまで次のスライドへ進めません
- **体験問題**：宛先シミュレーター、POP と IMAP の比較、仕分け、BCC、あやしいメールの判定など、自分で操作する問題
- **確認問題**：章の終わりと最後のまとめテスト。まとめテストの結果画面はスクリーンショットで提出する想定です（結果はサーバに保存されません）

パワーポイントのスライドのように、画面下の「前へ」「次へ」ボタンやスライドのクリック・タップで1枚ずつ進めます（← → ・スペースキーでも操作できます。問題のスライドではクリックで進みません）。

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run lint
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして次の2か所に公開します。

- GitHub Pages: https://renly24.github.io/edu-email-simulator/ （Settings → Pages で Source を「GitHub Actions」にしておく）
- FTP サーバー: http://e.gmobb.jp/omaesensei/digital/edu-email-simulator/ （`.github/workflows/deploy-ftp.yml`）

FTP へのアップロードには、リポジトリの Settings → Secrets and variables → Actions に `FTP_HOST`・`FTP_USER`・`FTP_PASS` の3つを登録しておく必要があります（edu-deploy-workflows の「Sync FTP secrets to repositories」でコピーできます）。
